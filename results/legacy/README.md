# Legacy aggregates: not validated model performance

These artifacts predate the November 6, 2026 audit. They are retained for traceability,
not as a current benchmark. Mock-labeled files test program execution only. Other
files lack sufficient run provenance and are labeled unverified, not automatically mock.
Patient-level identifiers, image paths and report excerpts have been removed from
this version. Old plots were withdrawn because they lack verified provenance.
The originals remain in Git history; this change does not erase historical content.

The original comparison used mock mode. Its entity-overlap heuristic has been
renamed. Other historical zeros cannot reliably distinguish failed evaluators from
measured zero scores, and must not be interpreted as model performance.
